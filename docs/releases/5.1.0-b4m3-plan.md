## 2. イメージビルド（Artifact Registry のみ）

作業ディレクトリ: `b4m-inner/cells/containers/cells/`

本番が参照している `:5.1.0-oidc-coldstart` を上書きしないよう、**b4m3 専用タグ**で push する。

### 2a. OIDC バイナリ置換 (`cloudbuild.yaml`)

Dockerfile は upstream `v5.1.0` clone + patches 001〜005（ソースは `5.1.0-b4m3` の OAuth 差分と同一であることを PR #7 で確認済み）。

```bash
cd containers/cells
gcloud builds submit --project=b4m-backyard --config=cloudbuild.yaml \
  --substitutions=_TAG=5.1.0-b4m3 .
# digest を控える（:5.1.0 も同時タグされる点に注意）
gcloud artifacts docker images describe \
  asia-northeast1-docker.pkg.dev/b4m-backyard/cells/cells:5.1.0-b4m3 \
  --format='get(image_summary.digest)'
```

出力: `asia-northeast1-docker.pkg.dev/b4m-backyard/cells/cells:5.1.0-b4m3`  
（cloudbuild.yaml 既定では加えて `:5.1.0` も付く）

### 2b. Coldstart 重ね (`cloudbuild.coldstart.yaml`)

```bash
OIDC_DIGEST=sha256:<2a の digest>
gcloud builds submit --project=b4m-backyard --config=cloudbuild.coldstart.yaml \
  --substitutions=_TAG=5.1.0-b4m3-coldstart,_BASE_IMAGE=asia-northeast1-docker.pkg.dev/b4m-backyard/cells/cells@${OIDC_DIGEST} .
```

出力: `asia-northeast1-docker.pkg.dev/b4m-backyard/cells/cells:5.1.0-b4m3-coldstart`

## 4. デプロイ日（実行しない・案のみ）

今夜 20 時以降、PO 指示後。事前に sakai の Cells MySQL をダンプしてから Cloud Run を新 digest に更新する。

### 4a. sakai DB ダンプ案（Cells は MySQL DB `cells`）

```bash
# IAP / SSH で sakai へ（実際の接続方法は inventory に従う）
gcloud compute ssh sakai --project=b4m-common --zone=<sakai-zone> --tunnel-through-iap

# sakai 上（compose ディレクトリは /opt/sakai 想定）
cd /opt/sakai
STAMP=$(date -u +%Y%m%dT%H%M%SZ)
docker compose exec -T mysql \
  mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" \
  --single-transaction --routines --triggers cells \
  | gzip -c > "/var/tmp/cells-pre-5.1.0-b4m3-${STAMP}.sql.gz"
# GCS へ退避（バケットは運用に合わせて変更）
gcloud storage cp "/var/tmp/cells-pre-5.1.0-b4m3-${STAMP}.sql.gz" \
  gs://b4m-backyard-cells-spike-default/db-dumps/
```

パスワードは Secret Manager `cells-mysql-password` / Ansible vault を使い、ログに出さない。
